> A mix of **ed-tech SaaS, machine learning APIs, and campus platforms** — the projects below span Next.js full-stack apps, FastAPI + PyTorch vision systems, and animated frontend builds.

Browse a tabular **database view** of every project → [[Projects.base|Database view]].

## Machine Learning

- **[[projects/ekalavya|Ekalavya]]** *(In Progress)* — credit-based, gamified ed-tech SaaS with **multiplayer quizzes**, **AI voice tutors**, leaderboards, and a referral-driven credit economy, built with Next.js + Supabase + Stripe. Supports **100+ concurrent quiz users**.
- **[[projects/netrai|NetrAI]]** *(In Progress)* — computer vision API platform with **image colorization** and **super-resolution**, built on FastAPI + PyTorch with JWT-secured access, metered Stripe billing, and async inference pipelines.
- **[[projects/sapplinn|Sapplinn]]** *(Completed)* — AgriTech platform for **smart crop prediction** and soil monitoring using Next.js + FastAPI, with transformer-based models and rate-limited APIs.

## Full Stack

- **[[projects/bitlog|BITLOG]]** *(Completed)* — developer-focused blog platform on Next.js with **PostgreSQL (Drizzle + Neon)**, NextAuth, PWA support, and an AI-assistant roadmap.
- **[[projects/fictora|Fictora]]** *(Completed)* — entertainment discovery hub built with Next.js and the **TMDB API**, expanding to anime (Jikan) and books (Google Books).
- **[[projects/nicogauge|NicoGauge]]** *(Completed)* — Next.js tool that computes a personalized **NeuroMarketing Index** from a neuromarketing-driven questionnaire (React Hook Form + Zod, privacy-first, no login).

## Frontend & Campus Websites

- **[[projects/ird-dtu|IRD-DTU]]** *(Completed)* — full-stack ERP and public website for DTU's Industrial Research & Development Unit: proposal submission, JWT role-based access, versioned file management, and email alerts (Node.js + PHP + MySQL).
- **[[projects/limstir-dtu|LIMSTIR-DTU]]** *(Completed)* — responsive portfolio website for the LIMSTIR innovation lab at DTU, with project archives, faculty profiles, and a media gallery (Tailwind + vanilla JS).
- **[[projects/society-of-robotics-dtu|Society of Robotics - DTU]]** *(Completed)* — animated, accessibility-first platform for a 100+ member robotics society using Next.js, GSAP, and Framer Motion.
